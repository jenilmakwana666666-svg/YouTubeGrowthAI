# YouTube Growth AI — Phone-only Cloud Build

1. Extract this ZIP.
2. Create a GitHub repository named `YouTubeGrowthAI`.
3. Upload the CONTENTS of `YouTubeGrowthAI-main` so that `app/` and `.github/` are at repository root.
4. Open GitHub -> Actions -> Build Android APK -> Run workflow.
5. Wait for the green check.
6. Open the completed workflow and download the `YouTubeGrowthAI-debug` artifact.
7. Extract the artifact and install `app-debug.apk` on your Android phone.
8. In the app, tap `SELECT GGUF MODEL` and choose a compatible GGUF model file.
9. After the model is ready, enter a topic such as `Goku vs Vegeta` and tap `GENERATE`.

The GGUF model is intentionally NOT included in this ZIP. It must be selected separately in the app.
